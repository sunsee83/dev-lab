# Dev Lab

여러 개발·실험 프로젝트를 한 저장소에서 관리하는 공개 작업 공간입니다.

## 사용 방법

- 프로젝트마다 하위 폴더 하나를 만들어 관리합니다.
- 폴더 이름만 보고 무엇을 만드는 프로젝트인지 알 수 있게 짓습니다.
- 기본 형식은 **`종류-대상-기능`** 순서를 권장합니다.

예시:
- `extension-instagram-research/` — Instagram 리서치 브라우저 확장앱
- `extension-youtube-tools/` — YouTube용 브라우저 확장앱
- `webapp-content-analyzer/` — 콘텐츠 분석 웹앱
- `ai-transcript-tool/` — AI 대본 분석 도구
- `automation-file-organizer/` — 파일 정리 자동화 도구

## 원칙

- `test1`, `new-project`처럼 의미가 불분명한 이름은 사용하지 않습니다.
- 비밀번호, API Key, Access Token 등 민감정보는 올리지 않습니다.
- 공개해도 되는 코드와 파일만 저장합니다.
- 각 프로젝트의 설명과 설치법은 해당 폴더의 `README.md`에 적습니다.
