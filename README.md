# Dev Lab

개발·실험·분석 작업을 모아두는 개인 연구실입니다.
완성본보다 진행 중인 프로젝트, 실험 코드, AI 수정용 파일을 중심으로 관리합니다.

## Structure
- `colab/` — Google Colab 기반 실험·분석 작업
- 그 외 프로젝트는 목적별 폴더로 분리

## Rules
- 프로젝트마다 독립 폴더를 사용합니다.
- 각 폴더의 `README.md`에는 목적과 현재 상태만 간단히 기록합니다.
- 비밀번호, API 키, 토큰, 쿠키, 개인정보는 저장하지 않습니다.
- 대용량·임시·자동 생성 파일은 필요한 경우에만 커밋합니다.
