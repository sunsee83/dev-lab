# Dev Lab

공개 개발·실험 프로젝트를 모아두는 공간입니다.

## 폴더 이름
폴더명만 보고 **종류 + 대상 + 목적**을 알 수 있게 짓습니다.

예:
- `extension-ig-research` — Instagram 리서치 확장앱
- `extension-youtube-tools` — YouTube 확장앱
- `webapp-content-analyzer` — 콘텐츠 분석 웹앱
- `ai-transcript-tool` — AI 대본 도구
- `automation-file-organizer` — 파일 자동화

각 프로젝트 폴더의 `README.md`에는 목적, 주요 기능, 실행 환경, 현재 상태를 간단히 기록합니다.
민감정보는 저장하지 않습니다.
