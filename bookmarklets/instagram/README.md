# Instagram RI Bookmarklet

현재 활성 버전: **v0.9.4**

## 활성 파일

```text
bookmarklets/instagram/
├─ current.js
├─ bridge-stable.svg
├─ bookmarklet-url.txt
├─ README.md
└─ SPEC.md
```

이 5개만 활성 파일로 유지한다. 과거 버전은 Git 기록으로 확인한다.

## 실행 / 업데이트
- 일반 실행은 휴대폰에 캐시된 `current.js`를 바로 실행한다.
- 최신 확인은 사용자가 `RI 업데이트`를 눌렀을 때만 수행한다.
- 북마크 주소는 정상적인 기능 업데이트마다 다시 교체하지 않는다.
- Loader는 캐시 실행과 `window.__RI_LOADER_REFRESH`만 제공한다.
- 본체가 정상 실행되면 Loader의 별도 업데이트 버튼은 숨긴다.
- 본체 실행 실패 때만 Loader 버튼이 비상 복구용으로 남는다.

## 확장앱 참고 원칙
- `reels-inspector/**`는 **읽기 전용 참고자료**다.
- 해당 폴더의 코드·문서·테스트는 수정·삭제·정리·커밋하지 않는다.
- 완성 제품으로 간주하지 않고 계산식·UI 구조·상태 처리 중 필요한 부분만 선별 참고한다.
- 북마클릿은 별도 런타임과 별도 저장공간을 사용한다.

## 현재 확인된 저장 엔진

- Reel 음원 단독 저장

## v0.9.2 확인 결과
- Grid UI를 카드 내부 DOM에 직접 붙인 뒤 스크롤 흔들림은 실기기에서 해소됨.
- 다만 화면에 표시되는 UI가 아직 과하고, 개발용 팝업/알림이 실제 사용을 방해함.
- Grid 다운로드 버튼이 Instagram DOM 재사용 시 일부 카드에서 생겼다 없어지는 현상도 확인됨.

## v0.9.3 — UI 구조 재정리

### Grid
- 카드 내부 UI 방식은 유지한다. 스크롤 좌표를 다시 계산하지 않는다.
- 빠른 저장은 **좌측 위 작은 원형 다운로드 아이콘** 하나만 유지한다.
- Instagram native Reel / 슬라이드 유형 아이콘은 그대로 둔다.
- 실제 수치가 아직 없는 동안 `-` placeholder 지표를 화면에 반복 표시하지 않는다.
- 수치 엔진이 연결되면 하단 gradient 위에 2행 × 4칸 지표만 표시한다.
- scroll 시 좌표는 건드리지 않지만 카드 DOM 재사용을 감지하기 위해 가벼운 재스캔을 수행한다.
- 버튼 이벤트는 생성 시 캡처한 shortcode가 아니라 **클릭 시점의 현재 anchor href**에서 다시 읽는다.

### Grid 저장 메뉴
- 영상 / Reel: `영상 | 음원 / 이미지 | 3개 모두`
- 사진: `사진 저장`
- 슬라이드: `슬라이드 전체`
- 메뉴는 전체 화면 중앙 팝업이 아니라 **누른 카드의 저장 아이콘 옆에 붙는 작은 메뉴**로 표시한다.

### 알림 / 작업 상태
- 화면 하단에 지속적으로 떠 있는 Activity / Toast를 기본 UI에서 제거한다.
- 사용자가 파일 선택을 취소한 `AbortError`는 **아무 알림도 표시하지 않는다**.
- Grid 저장 진행은 해당 다운로드 아이콘 자체에서 `↓ → … → ✓ / !`로 표시한다.
- 오류가 필요한 경우에만 화면 상단에 작은 임시 알림을 표시한다.
- 리서치 창이 열려 있을 때는 저장 상태를 창 내부에 표시한다.

## v0.9.4 — P0.5 화면 충돌 안정화

사용자 실기기 스크린샷에서 다음 문제가 확인되어 수정했다.

### Grid 버튼 수명주기
- 현재 Grid 후보 anchor 목록을 매 재스캔마다 다시 만들고, 더 이상 후보가 아닌 anchor에 남은 RI UI를 즉시 제거한다.
- Instagram이 anchor DOM을 재사용하거나 href를 바꾸더라도 오래된 다운로드 버튼이 남지 않도록 했다.
- `href` attribute 변경도 MutationObserver 감시 대상에 포함했다.
- 카드 후보 판정은 overlay 배치를 위한 viewport 좌표 계산 대신 `offsetWidth / offsetHeight` 기반으로 제한한다.
- 카드 overlay 자체에는 높은 z-index를 주지 않아 Instagram 고정 하단 navigation 위로 다운로드 버튼이 뚫고 올라오는 현상을 막는다.

### Native UI 충돌 방지
- Grid 하단 navigation은 RI보다 위에 표시되어야 한다.
- Grid 저장 메뉴는 화면 최하단 안전영역을 침범하지 않도록 아래쪽 여유를 둔다.
- Reel 화면에서는 RI launcher를 우측 action rail에서 분리해 좌측으로 이동한다.
- Research sheet가 열리면 뒤쪽 RI launcher는 숨긴다.

### Research UI 크기 조정
- compact sheet 최대 높이를 더 줄였다.
- 저장 버튼과 헤더 높이를 축소했다.
- 설정 화면을 3열 × 2행의 작은 구조로 바꿔 세로 점유를 줄였다.
- 상세 화면은 실제 상세 데이터가 아직 없는 동안 고정 72vh로 크게 펼치지 않고 콘텐츠 높이만큼만 열린다.

> **검증 상태:** v0.9.4 코드는 반영했지만 Android Edge 실기기 PASS 전이다.

## 리서치 창 구조

기존 큰 진단 패널을 기본 UI로 사용하지 않는다.

```text
RI [작은 원형 진입 버튼]
└─ 간단 보기 [작은 하단 시트 · 기본]
   ├─ 현재 콘텐츠
   ├─ 즉시 작업
   ├─ 더보기
   ├─ 상세
   └─ 닫기

상세 [사용자가 직접 펼칠 때만]
├─ 요약
├─ 콘텐츠
├─ 댓글
├─ 분석
└─ 미디어

더보기 / 전역
├─ 기본 다운로드
├─ 지정 폴더
├─ 매번 선택
├─ 업데이트
├─ 진단 복사
└─ 종료
```

- 기본 간단 보기는 화면을 거의 가리지 않는 작은 높이로 유지한다.
- 상세 시트는 사용자가 명시적으로 `상세`를 눌렀을 때만 확장한다.
- 상세 데이터가 비어 있는 단계에서는 불필요한 큰 빈 공간을 만들지 않는다.
- PASS / WAIT / FAIL 진단 목록은 일반 사용자 화면에서 제거한다.
- 진단 데이터는 `진단 복사`로만 접근한다.

## 실기기 완료 기준
- Instagram 원래 3열 Grid가 변하지 않는다.
- Grid 지표/저장 버튼이 카드와 분리되어 흔들리지 않는다.
- 카드 DOM 재사용 중에도 다운로드 버튼이 안정적으로 유지된다.
- Grid UI가 Instagram 고정 하단 navigation 위로 올라오지 않는다.
- Reel RI launcher가 Instagram 우측 action rail을 침범하지 않는다.
- 선택한 콘텐츠와 저장 파일/수치 shortcode가 일치한다.
- 확인되지 않은 수치는 `0`이나 placeholder로 화면을 채우지 않는다.
- 사용자가 취소한 작업은 오류 알림으로 표시하지 않는다.
- 영상은 소리 포함 정상 재생된다.
- 지정 폴더 모드의 모든 저장 진입점이 같은 폴더를 사용한다.
