# Instagram RI Bookmarklet

현재 활성 버전: **v0.8.6**

## 활성 파일

```text
bookmarklets/instagram/
├─ current.js
├─ bridge-stable.svg
├─ bookmarklet-url.txt
├─ README.md
└─ SPEC.md
```

이 5개만 활성 파일로 유지한다. 과거 버전은 Git 기록으로 확인한다.

## 실행 / 업데이트
- 일반 실행은 휴대폰에 캐시된 `current.js`를 바로 실행한다.
- 일반 실행에서는 업데이트용 외부 창을 열지 않는다.
- `RI 업데이트`를 직접 눌렀을 때만 최신 `current.js`를 받아 캐시를 교체한다.
- 정상적인 기능 수정은 `current.js`만 갱신한다.

## 확장앱 참고 원칙
- `reels-inspector/**`는 읽기 전용 참고자료다.
- 해당 폴더의 코드·문서·테스트를 수정하거나 삭제하지 않는다.
- 완성 제품으로 간주하지 않고 계산식·UI 구조·상태 처리 중 필요한 부분만 참고한다.
- 북마클릿은 별도 런타임과 별도 저장공간을 사용한다.

## 현재 확인된 저장 동작
- Reel 소리 포함 영상 저장
- Reel 음원 단독 저장
- Reel 이미지 저장
- 단일 사진 원본 저장
- 캐러셀 전체 개별 저장
- 기본 다운로드
- 지정 폴더 저장
- shortcode 중심 파일명
- 실시간 재인코딩 없이 영상 저장

## v0.8.6 그리드 저장
- 카드 `저장`을 누르면 즉시 일괄 다운로드하지 않는다.
- 영상 / Reel: `영상 저장` / `음원 저장` / `이미지 저장` / `3개 모두 저장` 중 선택한다.
- 사진: `원본 사진 저장`.
- 슬라이드: `전체 개별 저장`.
- 선택하지 않은 항목은 자동 저장하지 않는다.

## 통합 UI 방향

```text
RI 리서치 시스템
├─ 화면 정보

│  └─ Feed 최소 지표
├─ 빠른 작업
│  └─ 선택형 저장
├─ 공통 진입
│  └─ 리서치
├─ 콘텐츠 리서치
│  ├─ 간단 보기
│  └─ 상세 보기
│     ├─ 요약
│     ├─ 콘텐츠
│     ├─ 댓글
│     ├─ 분석
│     └─ 미디어
├─ 전역 관리
│  ├─ 저장
│  ├─ 데이터
```

기능이 추가될 때 임의의 빈 공간에 붙이지 않고 `SPEC.md`의 역할 레이어에 배치한다.

## 현재 작업 순서

### P0 — 선택 저장 실기기 확인
- 선택 메뉴가 먼저 열리는지
- 선택한 항목만 저장되는지
- 선택 카드와 저장 shortcode가 일치하는지

### P0.5A — 첫 UI 코드 적용
- Instagram 원래 3열 Grid 유지
- 콘텐츠 유형 자리 [우측 위]
- 빠른 저장 [좌측 아래]
- Grid 지표 2행 자리 확보
- 저장 선택 UI와 진행 상태 UI 분리
- 공통 Activity: 확인 / 저장 / 오류

### P0.5B — 리서치 진입 / 창 골격
- 공통 `리서치` 진입
- 간단 보기 / 상세 보기
- 상세 메뉴: 요약 / 콘텐츠 / 댓글 / 분석 / 미디어
- 전역 리서치 기본 골격

### P0.6 — 수치 저장 / 계산
- 조회수 / 좋아요 / 댓글 / 재게시 / 게시일
- 참여율
- 24시간 snapshot
- 같은 계정 최근 게시물 중앙값 대비 계정대비
- 북마클릿 전용 history 사용
- missing 값을 0으로 생성하지 않음

### P0.7 — 실제 수치 연결
- Grid: 조회수 | 좋아요 | 댓글 | 재게시
- Grid: 참여율 | 24시간 | 계정대비 | 게시일
- Reel: 조회수 / 참여율 / 24시간 / 계정대비 / 게시일
- Feed: 참여율 / 24시간 / 계정대비 / 게시일
- 같은 값 재렌더링을 피해서 flicker 방지

### P1 — 콘텐츠 인식 / API 실패 보강
- Instagram API 404 실패 경로 확인
- 잘못된 인접 카드 fallback 금지
- 저장과 수치가 같은 shortcode를 사용하도록 고정

### P2 — 지정 폴더 지속성
- Edge 재실행 후 폴더 핸들 복원
- 권한 만료 시 저장 시점에만 재요청

### P3 — 미디어 최종 검증
- 실제 표지 우선
- 표지 없으면 정확한 0.000초 첫 프레임
- 영상 저장 수 초 수준 확인

### P4 이후
- P4: 본문 / 해시태그 / 언급 계정
- P5: 댓글 / 답글 / 실제 수집 범위
- P6: 음성 변환 / 화면 글자
- P7: 콘텐츠 / 댓글 분석
- P8: 저장 기록 / 수치 기록 / JSON / CSV 등 전역 데이터 관리

## 첫 구현 범위
다음 코드 변경은 `current.js`에서 **Grid + 빠른 저장 + Activity**만 다룬다. 리서치 창과 수치 계산을 동시에 넣지 않는다.

## 실기기 완료 기준
- Instagram 원래 3열 Grid가 변하지 않는다.
- 저장 버튼이나 수치 때문에 카드 크기·행 높이가 바뀌지 않는다.
- 선택한 콘텐츠와 저장 파일/수치의 shortcode가 일치한다.
- 확인되지 않은 수치는 `0`이 아니라 missing 상태다.
- 영상은 소리 포함 정상 재생된다.
- 지정 폴더 모드의 모든 저장 진입점이 같은 폴더를 사용한다.
