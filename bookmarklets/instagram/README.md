# Instagram Bookmarklet

현재 인스타그램용 북마클릿의 코드 배치 원칙입니다.

## 북마크 URL 안

- Instagram 전용 핵심 판별 로직
- 콘텐츠 식별 규칙
- 중요한 짧은 추출 로직
- 외부 본체와 연결하는 코드

## GitHub 공개 코드

- UI
- 파일 저장
- IndexedDB
- 썸네일 생성
- CSV/JSON 출력
- 일반적인 유틸리티

## 원칙

북마크 URL에는 길이 제한 안에서 인스타그램 전용 핵심 로직을 우선 배치하고, 크기가 크거나 일반화 가능한 기능은 GitHub 공개 코드로 분리합니다.

이 폴더는 현재 Instagram 전용입니다. 향후 기능 범위가 여러 SNS로 확장되면 폴더명과 구조를 그 시점에 다시 정리합니다.
