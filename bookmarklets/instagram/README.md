# Instagram RI Bookmarklet

현재 활성 버전: **v0.9.6**

## 활성 파일

```text
bookmarklets/instagram/
├─ README.md
├─ SPEC.md
├─ bookmarklet-url.txt
├─ bridge-stable.svg
└─ current.js
```

활성 파일은 정확히 위 5개만 유지한다. 과거 버전은 Git history로 관리한다.

`reels-inspector/**`는 **읽기 전용 참고자료**다. 수정·삭제·정리·커밋하지 않는다.

## 실행 / 업데이트

- `current.js`는 평문 JS 본체다.
- 일반 실행은 휴대폰 캐시의 본체를 사용한다.
- `RI 업데이트`를 누르면 GitHub 최신 `current.js`를 받아 캐시를 교체한다.
- 정상적인 기능 업데이트마다 북마크 주소를 교체하지 않는다.
- 본체 정상 실행 시 Loader의 별도 업데이트 버튼은 숨긴다.
- 본체 실행 실패 때만 Loader 버튼을 비상 복구용으로 사용한다.

## 저장 엔진 기준

기존 Android Edge 실기기에서 확인된 기반 기능:

- Reel 소리 포함 영상 저장
- Reel 음원 단독 저장
- Reel 이미지 저장
- 단일 사진 원본 저장
- 캐러셀 전체 개별 저장
- 기본 다운로드 / 지정 폴더 / 매번 선택
- shortcode 기반 짧은 파일명
- MediaRecorder 실시간 재인코딩 사용 안 함

영상 저장 성공은 **소리 포함 정상 MP4** 기준이다.

## v0.9.5 문제 원인

v0.9.5는 팝업 외형을 줄이는 데 집중하면서 제품 전체 UI 구조를 충분히 연결하지 못했다.

핵심 원인:

1. **Grid 수치 렌더러가 사실상 비활성 상태였다.**
   - `metricValues()`가 값을 반환하지 않아 8-slot 영역이 계속 숨겨졌다.
   - 결과적으로 저장 버튼만 남고 RI의 핵심 목적인 비교 지표가 사라졌다.

2. **기존 확장프로그램의 검증된 Grid 표시 구조를 충분히 이식하지 않았다.**
   - `reels-inspector`의 카드 내부 하단 gradient
   - 2행 × 4칸 고정 슬롯
   - `tabular-nums`
   - 고정 슬롯 폭
   - 1행 강한 shadow / 2행 white stroke
   구조를 참고해야 했는데 v0.9.5에서는 시각 시스템만 새로 만들고 데이터 연결을 미뤘다.

3. **UI를 팝업 단위로만 수정했다.**
   - Grid
   - Reel 화면 지표
   - 간단 보기
   - 요약 / 콘텐츠 / 댓글 / 분석 / 미디어 탭
   - 저장 / 데이터 / 리서치 설정 / 업데이트
   을 하나의 제품 UI 시스템으로 같이 설계해야 했는데 일부 화면만 변경했다.

4. **미구현 탭을 단순 placeholder로 처리했다.**
   - 기능이 아직 연결되지 않아도 각 탭의 최종 정보 구조와 밀도는 먼저 완성되어 있어야 한다.

## v0.9.6 — 전체 UI + 수치 표시 복구

### Grid

`reels-inspector`의 좋은 부분을 읽기 전용으로 참고해 다시 구현했다.

```text
1행: ▶조회수 | ♥좋아요 | ●댓글 | ↻재게시
2행: 참여율 | 24시간 | 계정대비 | 게시일
```

표시 방식:

- Instagram 카드 anchor 내부 `absolute` 부착
- 하단 gradient
- 2행 × 4칸 고정 슬롯
- `font-variant-numeric: tabular-nums`
- 슬롯별 고정 폭
- 1행: 흰색 + 강한 shadow
- 2행: 어두운 글자 + 흰 stroke
- 값이 없는 슬롯은 빈 칸으로 유지하고 `0`이나 `-`를 만들어 채우지 않음
- 카드 전체에 실제 값이 하나도 없을 때만 지표 영역 전체 숨김

Grid 저장 아이콘은 좌측 상단 27px 원형 SVG로 유지한다.

### Grid 수치 수집

북마클릿 전용 `localStorage` 저장공간을 사용한다.

콘텐츠별 최소 구조:

```text
shortcode
├─ username
├─ type
├─ postedAt
├─ views
├─ likes
├─ comments
├─ reposts
├─ updatedAt
└─ history[]
   ├─ t
   └─ v
```

- 현재 보이는 Grid 주변 카드부터 낮은 동시성으로 원본 정보를 확인한다.
- Instagram API를 무제한 병렬 호출하지 않는다.
- 최근 확인 데이터는 짧은 시간 동안 재사용한다.
- 확장프로그램 저장공간과 공유하지 않는다.

### 파생 지표

확장프로그램의 계산 규칙을 선별 참고했다.

- 참여율: `(좋아요 + 댓글 + 재게시) / 조회수 × 100`
- 24시간: 18~32시간 snapshot 중 24시간에 가장 가까운 기록
- 계정대비: 같은 계정 최근 게시물 최대 20개, 최소 5개, 조회수 중앙값 대비 배수
- 계산 조건이 부족하면 빈 값으로 유지한다.

### Reel 화면

Instagram 우측 action rail은 건드리지 않는다.

실제 값이 있을 때만 영상 영역 좌측에 작은 핵심 지표를 표시한다.

- 조회수
- 참여율
- 24시간
- 계정대비
- 게시일

박스형 패널이 아니라 텍스트 중심 overlay다.

### RI 간단 보기

기존의 큰 floating card 느낌을 줄이고 **edge-to-edge bottom sheet**로 변경했다.

기본 구성:

```text
현재 계정 · 유형                    ×
실제 핵심 지표 [있는 경우만]
저장       현재 저장 방식       상세   •••
```

- 화면 좌우 전체를 사용해 좁은 카드 안에 요소가 몰리는 느낌을 줄임
- 저장은 대표 버튼 하나
- 상세 / 관리는 보조 동작
- 실제 수치가 있으면 compact strip으로 표시
- 작업 상태는 작업 중일 때만 내부에 표시

### 상세 탭

상세 UI는 다음 5개 탭 전체를 구현한다.

```text
요약 | 콘텐츠 | 댓글 | 분석 | 미디어
```

요약:
- 기본/파생 수치를 compact KPI로 표시
- 계정 / 유형 / shortcode / 저장 방식

콘텐츠:
- 본문
- 해시태그 / 언급
- STT
- OCR

댓글:
- 전체 댓글 / 수집 / 답글 요약
- 질문 / 구매의도 / 긍정 / 불만 / 반론 / 팁·정보
- 원문 / 답글 영역

분석:
- 시작 훅 / 첫 메시지
- 도입 / 전개 / 핵심 / 마무리
- CTA / 강조 / 숫자 / 가격

미디어:
- 현재 콘텐츠 유형에 맞는 저장 항목

미연결 기능은 큰 빈 화면 대신 **완성된 정보 구조 안에서 작은 상태 카드**로 표시한다.

### 전역 관리

`•••`에서 다음 구조를 사용한다.

```text
관리
├─ 저장
├─ 데이터
├─ 리서치 설정
└─ 업데이트

시스템
├─ 진단 복사
└─ RI 종료
```

저장:
- 기본 다운로드
- 지정 폴더
- 매번 선택

데이터:
- 저장된 콘텐츠 수
- snapshot 수
- 계정 수

리서치 설정:
- 댓글
- STT
- OCR
- 분석

## 알림 정책

- 지속적인 하단 Activity / Toast 금지
- `AbortError`는 정상 취소이므로 무알림
- Grid 저장 진행은 해당 카드 버튼 자체에서 표시
- RI sheet가 열려 있으면 작업 상태는 sheet 내부 표시
- 실제 오류만 상단 임시 알림

## 다음 실기기 확인

한 번에 하나만 본다.

첫 확인은 **Grid UI**다.

1. `RI 업데이트`
2. 프로필 Grid 진입
3. 저장 버튼은 누르지 않음
4. Grid만 확인
   - 실제 조회/좋아요/댓글/재게시 값이 확보된 카드에 1행 수치가 보이는지
   - 파생값이 확보된 경우 2행에 표시되는지
   - 값이 없는 슬롯이 `-`로 도배되지 않는지
   - 확장프로그램에서 참고한 2행 × 4칸 고정 정렬이 유지되는지
   - 스크롤 시 카드와 지표가 같이 움직이는지

이 테스트가 끝난 뒤에만 다음 UI를 확인한다.

## 실기기 완료 기준

- Instagram 원래 3열 Grid 크기/행 높이가 변하지 않는다.
- Grid 지표가 카드 내부에 붙어 흔들리지 않는다.
- 실제 값이 있는 카드에서는 8-slot 구조가 다시 보인다.
- 값이 없다는 이유로 `-` placeholder가 화면을 덮지 않는다.
- Reel 우측 native action rail을 침범하지 않는다.
- 간단 보기와 상세 탭의 역할이 명확히 분리된다.
- 사용자가 취소한 작업은 오류처럼 보이지 않는다.
- 영상은 소리 포함 정상 재생된다.
