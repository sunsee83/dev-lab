# Instagram RI 미디어 저장 규칙

## 사용자에게 보이는 저장 기능
- 릴스 / 영상: `영상 저장` = 소리 포함 정상 영상
- 릴스 / 영상: `음원 저장` = 음원만
- 릴스 / 영상: `이미지 저장` = 실제 표지 우선, 표지가 없으면 0.000초 첫 프레임
- 사진 게시물: `사진 저장` = 원본 사진
- 슬라이드 / 캐러셀: `캐러셀 전체 저장` = 사진·영상 혼합 여부와 관계없이 원본을 순서대로 전체 저장
- 무음 영상 트랙은 내부 처리용으로만 사용하며 일반 UI에는 노출하지 않는다.

## 그리드 저장
- 3열 그리드에서 자동 대상 판별 시 화면 중앙 행에서 화면에 완전히 보이는 가장 왼쪽 카드를 우선한다.
- 각 카드의 `저장` 버튼은 즉시 파일을 내려받지 않고 해당 카드를 현재 저장 대상으로 선택한 뒤 RI 상태 팝업을 연다.
- 카드 선택 후 영상 / 음원 / 이미지 / 사진 / 캐러셀 전체 저장 버튼을 사용한다.
- 그리드 저장도 현재 저장 위치 설정을 그대로 사용하므로 지정 폴더 저장이 가능하다.

## 영상 저장 속도
- 실시간 재생·녹화·재인코딩을 사용하지 않는다.
- Instagram의 소리 포함 완성 MP4를 직접 받아 저장한다.
- 처리 목표는 수 초, 기준 목표는 약 5초 이내다.
- 실제 완료 시간은 파일 크기와 네트워크 속도의 영향을 받으므로 절대 시간을 보장하지 않는다.
- 완성 영상 직접 저장이 불가능하면 느린 재인코딩으로 몰래 대체하지 않고 오류/미지원 상태로 표시한다.

## 저장 위치
- 기본 다운로드
- 지정 폴더
- 매번 선택(브라우저 지원 시)
- 지정 폴더 핸들은 IndexedDB에 저장하고 재실행 시 복원한다.
- 지정 폴더 권한이 만료된 경우 저장 시 권한을 다시 요청한다.

## 짧은 파일명 규칙
shortcode 자체가 게시물 고유 식별자이므로 계정명을 파일명에서 제외한다.

- 영상: `IG_{shortcode}.mp4`
- 음원: `IG_{shortcode}_a.m4a`
- 실제 표지: `IG_{shortcode}_c.{ext}`
- 표지 없는 영상 첫 프레임: `IG_{shortcode}_f.jpg`
- 단일 사진: `IG_{shortcode}.{ext}`
- 캐러셀: `IG_{shortcode}_01.{ext}`, `IG_{shortcode}_02.{ext}` ...
- 캐러셀의 영상 항목은 같은 순번에 `.mp4`를 사용한다.

## 이미지 원칙
- 실제 표지가 있으면 해당 원본 표지를 저장한다.
- 실제 표지가 없을 때만 영상 0.000초의 첫 표시 프레임을 저장한다.
- 임의의 중간 장면이나 가장 선명한 장면을 대표 이미지로 선택하지 않는다.

## 캐러셀 원칙
- 사진 / 영상 / 혼합 캐러셀을 모두 지원한다.
- 원래 순서를 유지한다.
- 영상 슬라이드는 소리 포함 완성 영상을 저장한다.
- 전체 저장은 최대 3개 항목을 병렬로 받아 불필요한 대기 시간을 줄인다.

## 상태 정보 UI
- PASS / PARTIAL / FAIL / WAIT 상태 정보는 UI가 변경되더라도 유지한다.
- 현재 콘텐츠, 대상 선택 방식, 미디어 정보, 저장 위치, 각 저장 결과를 확인할 수 있어야 한다.
