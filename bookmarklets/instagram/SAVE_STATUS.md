# 저장 기능 상태

## 기기에서 확인됨
- 릴스 소리 포함 영상 저장
- 릴스 음원 단독 저장
- 기본 다운로드

## v0.8.1 구현 완료 · 기기 확인 필요
- 릴스 / 일반 영상: 소리 포함 원본 영상 직접 저장
- 릴스 / 일반 영상: 음원 단독 저장
- 명시적 표지가 있으면 원본 표지 저장
- 명시적 표지가 없으면 0.000초 첫 프레임 저장
- 단일 사진 원본 저장
- 사진 캐러셀 전체 저장
- 영상 캐러셀 전체 저장
- 사진+영상 혼합 캐러셀 전체 저장
- 캐러셀 원래 순서 유지 및 최대 3개 병렬 저장
- 지정 폴더 저장, 폴더 핸들 기억, 권한 재요청
- 기본 다운로드 / 지정 폴더 / 매번 선택 모드
- 프로필 3열 그리드 카드 빠른 저장
- 계정명 + shortcode 기반 파일명 규칙
- 저장 코어와 UI를 분리해 이후 저장 로직 수정 시 UI와 독립적으로 관리

## 저장 모드 제약
- `매번 선택`은 단일 파일 저장용이다.
- 캐러셀 전체 저장은 `기본 다운로드` 또는 `지정 폴더`를 사용한다.
- 그리드 빠른 저장도 `기본 다운로드` 또는 `지정 폴더`를 사용한다.

## 완료 판정 기준
- 저장된 미디어가 선택한 콘텐츠와 정확히 일치한다.
- 영상은 소리가 포함되고 정상 재생된다.
- 표지가 없는 영상의 이미지 fallback은 0.000초 첫 프레임이다.
- 캐러셀은 누락 없이 원래 순서대로 저장된다.
- 지정 폴더 선택 후 같은 폴더로 계속 저장되고 재실행 후 복원된다.
- 일반적인 릴스 영상 저장은 재인코딩 없이 직접 저장하며 목표 시간은 약 5초 이내다.
