# 저장 기능 상태

## 기기에서 확인됨
- Reel 소리 포함 영상 저장
- Reel 음원 단독 저장
- Reel 이미지 저장
- 기본 다운로드
- 지정 폴더 저장
- 캐러셀 전체 저장

## 현재 구현
- 영상/Reel: 영상 + 음원 + 이미지 저장
- 단일 사진: 원본 사진 1개 저장
- 캐러셀: 사진/영상/혼합을 원래 순서대로 전체 저장
- 그리드 카드 `저장`: 콘텐츠 유형을 판별해 위 저장 세트를 즉시 실행
- 그리드 저장도 현재 저장 위치 설정을 그대로 사용
- 파일명은 shortcode 중심의 짧은 규칙 사용
- 상태 팝업에 PASS / PARTIAL / FAIL / WAIT 유지
- 영상 저장은 재인코딩하지 않고 Instagram의 소리 포함 MP4를 직접 저장

## 추가 실기기 확인
- 그리드 영상 카드에서 영상 + 음원 + 이미지 3개가 모두 지정 폴더로 저장되는지
- 그리드 단일 사진/캐러셀 빠른 저장이 유형을 정확히 판별하는지
- 지정 폴더 권한이 재실행 후 정상 복원되는지
- 실제 표지가 없는 영상 이미지가 정확히 0.000초 첫 프레임인지

## 완료 기준
- 선택한 콘텐츠와 저장 파일의 shortcode가 일치한다.
- 영상은 소리가 포함되고 정상 재생된다.
- 캐러셀은 누락 없이 원래 순서를 유지한다.
- 지정 폴더 모드에서는 모든 저장 진입점이 같은 폴더를 사용한다.
- 한 항목이 실패해도 가능한 나머지 저장은 계속되고 상태창에 결과가 남는다.
