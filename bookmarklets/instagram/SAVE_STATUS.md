# 저장 기능 상태

## 기기에서 확인됨
- 릴스 소리 포함 영상 저장
- 릴스 음원 단독 저장
- 기본 다운로드

## v0.8.0 구현 완료 · 기기 확인 필요
- 릴스/영상 실제 표지 저장 → 없으면 0.000초 첫 프레임
- 지정 폴더 저장 및 폴더 핸들 복원
- 매번 저장 위치 선택(지원 브라우저)
- 단일 사진 원본 저장
- 사진 캐러셀 전체 저장
- 영상 캐러셀 전체 저장
- 사진+영상 혼합 캐러셀 전체 저장
- 프로필 3열 그리드 카드 빠른 저장
- 계정명 + shortcode 기반 파일명 규칙

## 완료 판정 기준
- 저장된 미디어가 선택한 콘텐츠와 정확히 일치한다.
- 영상은 소리가 포함되고 정상 재생된다.
- 이미지 fallback은 0.000초 첫 프레임이다.
- 캐러셀은 누락 없이 원래 순서대로 저장된다.
- 지정 폴더 선택 후 같은 폴더로 계속 저장되고 재실행 후 복원된다.
- 일반적인 릴스 영상 저장은 재인코딩 없이 직접 저장하며 목표 시간은 약 5초 이내다.
