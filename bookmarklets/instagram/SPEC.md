# Instagram RI — Specification

이 문서는 Instagram RI 북마클릿의 제품/UI/저장/수치 기준입니다.

## 1. 기준 원칙
- Instagram 원래 모바일 UI와 3열 Grid를 유지한다.
- 카드 크기·행 높이 변경, 불필요한 flicker를 만들지 않는다.
- shortcode를 저장·수치·댓글·분석의 공통 identity로 사용한다.
- missing / 미확인 값을 `0`으로 만들지 않는다.
- Instagram native action을 제거하거나 불필요하게 복제하지 않는다.
- 기능 실행 본체는 `current.js` 하나만 유지한다.
- `reels-inspector/**`는 **읽기 전용 참고자료**다. 북마클릿 작업에서 수정·삭제·정리·커밋하지 않는다.
- 기존 확장앱 구현은 완성본으로 간주하지 않고, 쓸 만한 계산/표시/상태 구조만 선별해 북마클릿용으로 다시 구현한다.

## 3. Grid 수치 규칙

```text
첫째 줄  조회수 | 좋아요 | 댓글 | 재게시
둘째 줄  참여율 | 24시간 | 계정대비 | 게시일
```

- 각 줄은 4개 fixed slot을 유지한다.
- 숫자 길이 때문에 slot 위치를 바꾸지 않는다.
- 같은 값이면 DOM을 다시 쓰지 않는 renderKey 방식을 사용한다.
- 사진/슬라이드의 확인되지 않은 조회수는 `-`로 표시한다.
- 실제 raw input이 없으면 숫자를 생성하지 않는다.

### 참여율
`(좋아요 + 댓글 + 재게시) / 조회수 × 100`

### 24시간
- 현재 조회수와 과거 snapshot을 사용한다.
- 18~32시간 범위의 실제 snapshot만 후보로 사용한다.
- 24시간에 가장 가까운 snapshot을 선택한다.

### 계정대비
- 같은 계정 최근 게시물의 조회수를 사용한다.
- 현재 게시물은 제외한다.
- 최대 최근 20개, 최소 5개 표본을 사용한다.
- 중앙값 대비 현재 조회수의 배수로 표시한다.

### 표시 형식
- 수치: `42.9만`, `1.2억`, `3.4K`
- 참여율: `0.55%`
- 24시간: `+8.2%`
- 계정대비: `×3.7`
- 게시일: `08/26`

## 4. 수치 저장 구조
24시간과 계정대비를 위해 북마클릿 전용 history를 사용한다.

```text
RI History
├─ 게시물 기록
│  ├─ shortcode
│  ├─ 계정명
│  ├─ 조회수
│  └─ 기록 시간
└─ 조회수 snapshot
   ├─ shortcode
   ├─ 조회수
   └─ 기록 시간
```

- `reels-inspector`의 `ri311:*` 저장 키를 공유하지 않는다.
- 북마클릿 전용 key를 사용한다.
- 기존 확장앱 데이터와 섞거나 변경하지 않는다.

## 5. 저장 규칙

### 영상 / 릴스
- `영상 저장` = 소리 포함 정상 MP4.
- `음원 저장` = 별도 음원 파일.
- `이미지 저장` = 실제 표지가 있으면 실제 표지, 없으면 정확한 0.000초 첫 표시 프레임.
- `3개 모두 저장`을 선택했을 때만 영상 + 음원 + 이미지를 모두 저장한다.
- 실시간 재생 녹화/재인코딩으로 몰래 fallback하지 않는다.

### 사진
- 원본 사진 1개를 저장한다.

### 슬라이드
- 사진 / 영상 / 혼합을 모두 지원한다.
- 원래 순서를 유지한다.
- ZIP으로 묶지 않고 개별 파일로 저장한다.

### 저장 위치
- 기본 다운로드
- 지정 폴더
- 매번 선택(단일 파일용)
- 지정 폴더 핸들은 IndexedDB에 저장하고 재실행 시 복원한다.
- 지정 폴더 실패 시 사용자 모르게 기본 다운로드로 fallback하지 않는다.

### 파일명
- 영상: `IG_{shortcode}.mp4`
- 음원: `IG_{shortcode}_a.m4a`
- 실제 표지: `IG_{shortcode}_c.{ext}`
- 첫 프레임: `IG_{shortcode}_f.jpg`
- 사진: `IG_{shortcode}.{ext}`
- 슬라이드: `IG_{shortcode}_01.{ext}`, `_02` ...

```text

      ├─ Reel 지표 자리
      └─ 리서치 창 CLOSED / 간단 보기 / 상세 보기

      ├─ 현재 기본 지표
      ├─ history
      ├─ 참여율

      └─ 계정대비

P1    identity / Instagram API 실패 경로 보강
```

UI를 먼저 완성형으로 채우지 않는다. 자리와 상태 전환을 먼저 고정하고, 확인된 데이터만 순차 연결한다.
