# YouTube 데이터 출력 / 로컬 저장

이 문서는 `YT_TOOL_DATA_RESULT`를 `원문 / TXT / JSON`으로 변환하고 Android 로컬 파일로 저장하는 **현재 일반 UI 규격**입니다.

YouTube 전용 추출 로직은 포함하지 않습니다.

## 1. 역할 분리

### 북마클릿 코어

- 사용자가 선택한 필드만 추출
- `YT_TOOL_DATA_RESULT` 반환
- 인증정보/세션값/미디어 스트림 URL을 결과에서 제외

### `ui.html`

- 결과를 현재 실행 메모리에 보관
- 선택한 형식으로 문자열 변환
- 로컬 저장용 파일명 생성
- 사용자가 고른 파일 핸들에 UTF-8로 기록

## 2. 원문

사람과 AI가 바로 읽기 좋은 정리형 텍스트입니다.

- 기본정보는 읽기 쉬운 항목명으로 표시
- 설명/대본은 별도 구역
- 태그는 목록 형태
- 댓글은 번호, 작성자, 시점, 좋아요, 본문을 구분
- 일부 필드 실패 시 오류 항목을 함께 표시
- 확장자 `.txt`

## 3. TXT

가공을 최소화한 평문 출력입니다.

- 기본 필드: `항목명: 값`
- 배열/객체는 읽을 수 있는 평문으로 변환
- 대본은 전체 텍스트 중심
- 댓글은 한 댓글씩 구분
- 확장자 `.txt`

## 4. JSON

```js
{
  videoId:'',
  requested:[],
  result:{},
  errors:{}
}
```

- UTF-8
- 2칸 들여쓰기
- 확장자 `.json`

## 5. 로컬 저장 순서

데이터 추출 전에 파일 선택창을 먼저 열어 사용자 동작 권한을 보존합니다.

```text
사용자 [저장]
→ 데이터 + 로컬이면 ui.html이 즉시 showSaveFilePicker()
→ 사용자가 파일 위치/이름 선택
→ FileSystemFileHandle을 현재 실행 메모리에만 유지
→ 코어에 save-local 요청
→ YT_TOOL_DATA_RESULT 수신
→ 선택 형식으로 변환
→ handle.createWritable()
→ 결과 기록
→ 핸들 폐기
```

파일 핸들은 `postMessage`, localStorage, IndexedDB, GitHub 코드에 저장하지 않습니다.

## 6. 파일명

영상 제목을 기준으로 파일명 금지 문자를 정리합니다.

```text
원문 → 영상 제목_원문.txt
TXT  → 영상 제목_데이터.txt
JSON → 영상 제목_데이터.json
```

영상 제목을 사용할 수 없으면 `YouTube_수집`을 사용합니다.

## 7. 복수 선택

`영상 + 음성 + 데이터` 동시 선택을 허용합니다.

- 미디어 파일 저장은 코어가 처리
- 데이터 파일은 UI가 미리 확보한 데이터용 파일 핸들에 기록
- 한 항목 실패가 다른 항목의 완료 결과를 취소하지 않음

## 8. 취소 / 오류

- 파일 선택 취소 → 데이터 로컬 저장 시작하지 않음
- 데이터 일부 실패 → 확보된 결과 저장 + 오류 항목 포함
- 파일 쓰기 실패 → 데이터 파일만 실패 처리
- 데이터 실패 → 영상/음성 저장 결과에 영향 없음

## 9. 실행 메모리

UI가 실행 중 보관할 수 있는 값:

```text
최신 YT_TOOL_DATA_RESULT
현재 데이터 저장용 FileSystemFileHandle
현재 선택 출력 형식
```

다음 경우 기존 데이터 결과를 폐기합니다.

```text
새 영상 초기화
데이터 선택 해제
수집 필드 변경
댓글 수량/정렬 변경
출력 형식 변경
```
