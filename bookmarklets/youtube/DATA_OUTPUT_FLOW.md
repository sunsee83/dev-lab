# YouTube 데이터 출력 / 로컬 저장

이 문서는 `YT_TOOL_DATA_RESULT`를 `원문 / TXT / JSON`으로 변환하고 Android 로컬 파일로 저장하는 일반 UI 로직 기준입니다.

YouTube 전용 추출 로직은 이 파일에 포함하지 않습니다.

## 역할 분리

### 북마클릿 코어

- 사용자가 선택한 필드만 추출
- `YT_TOOL_DATA_RESULT` 반환
- 인증정보/세션값/미디어 스트림 URL을 결과에서 제외

### 공개 UI

- 결과를 현재 실행 메모리에 보관
- 선택한 형식으로 문자열 변환
- 로컬 저장용 파일명 생성
- 사용자가 고른 파일 핸들에 UTF-8로 기록

## 형식

### 원문

사람과 AI가 바로 읽기 좋은 정리형 텍스트입니다.

- 기본정보는 읽기 쉬운 항목명으로 표시
- 설명/대본은 별도 구역
- 태그는 목록 형태
- 댓글은 번호, 작성자, 시점, 좋아요, 본문을 읽기 쉽게 배치
- 일부 필드 실패 시 마지막에 오류 항목을 표시
- 확장자: `.txt`

### TXT

가공을 최소화한 평문 출력입니다.

- 기본 필드는 `항목명: 값`
- 배열/객체는 사람이 읽을 수 있는 평문으로 펼침
- 대본은 전체 텍스트 중심
- 댓글은 한 댓글씩 구분
- 확장자: `.txt`

### JSON

구조화 결과를 그대로 보존합니다.

```js
{
  videoId: '',
  requested: [],
  result: {},
  errors: {}
}
```

- UTF-8
- 2칸 들여쓰기
- 확장자: `.json`

## 로컬 저장 순서

데이터 추출은 비동기이므로 Android 파일 선택창의 사용자 동작 권한을 잃지 않도록 순서를 고정합니다.

1. 사용자가 `[저장]`을 누름
2. `데이터 + 로컬`이면 UI가 즉시 `showSaveFilePicker()` 실행
3. 사용자가 폴더/파일명을 선택
4. UI는 선택된 `FileSystemFileHandle`을 현재 실행 메모리에만 보관
5. 그 다음 코어에 `save-local` 요청
6. 코어가 데이터 추출 후 `YT_TOOL_DATA_RESULT` 반환
7. UI가 선택한 `원문 / TXT / JSON` 형식으로 변환
8. `handle.createWritable()`로 결과 기록
9. 완료 후 파일 핸들과 데이터 결과는 다음 실행에 재사용하지 않음

파일 핸들은 `postMessage`, localStorage, IndexedDB, GitHub 코드에 저장하지 않습니다.

## 파일명

현재 영상 제목을 기준으로 파일명에 사용할 수 없는 문자를 제거합니다.

예:

- 원문: `영상 제목_원문.txt`
- TXT: `영상 제목_데이터.txt`
- JSON: `영상 제목_데이터.json`

영상 제목을 사용할 수 없으면 `YouTube_수집`을 기본 이름으로 사용합니다.

## 복수 선택

`영상 + 음성 + 데이터`를 동시에 선택할 수 있습니다.

- 미디어 파일 저장은 기존 코어 흐름을 유지
- 데이터 파일은 UI가 미리 확보한 데이터용 파일 핸들에 기록
- 데이터 출력 실패가 이미 완료된 영상/음성 저장 결과를 취소하지 않음

## 취소 / 오류

- 파일 선택창 취소: 전체 저장 요청을 시작하지 않고 `데이터 저장 취소됨` 표시
- 데이터 추출 일부 실패: 확보된 결과는 저장하고 오류 항목 포함
- 파일 쓰기 실패: 데이터 파일만 실패 처리
- 데이터 실패는 영상/음성 저장 결과에 영향을 주지 않음

## 메모리 규칙

UI가 실행 중 보관할 수 있는 값:

- 최신 `YT_TOOL_DATA_RESULT`
- 현재 데이터 저장용 `FileSystemFileHandle`
- 현재 선택 출력 형식

다음 경우 기존 결과를 폐기합니다.

- 새 영상으로 초기화
- 데이터 선택 해제
- 수집 필드 변경
- 댓글 수량/정렬 변경
- 출력 형식 변경

## 단계 7 완료 기준

- `YT_TOOL_DATA_RESULT` 수신
- `원문 / TXT / JSON` 변환 함수 연결
- 데이터 결과 실행 메모리 보관
- Android 파일 선택창을 저장 버튼의 사용자 동작 시점에 먼저 실행
- 결과 도착 후 선택 파일에 기록
- 파일 핸들/결과를 브라우저 저장소에 영구 저장하지 않음
