# YouTube 수집도구 UI 규격

이 문서는 `ui.html`의 **현재 화면 구조와 표시 조건**만 정의합니다.

## 1. 화면 구성

북마클릿은 하나이며 화면은 두 상태로 나뉩니다.

```text
설정 필요
→ YouTube 수집도구 설정

설정 완료
→ YouTube 수집
```

## 2. 설정 화면

```text
YouTube 수집도구 설정

[ Google 계정으로 계속 ]

Google Sheets 연결
[ Sheets 새로 만들기 ] [ 내 Sheets 열기 ]

파일 링크
[ https://docs.google.com/spreadsheets/d/... ]
[ 파일 연결 ]

연결된 파일
[ 파일 ▼ ]

기본 시트
[ 시트 ▼ ]
[ + 새 시트 ]

기본 카테고리
[ 카테고리 ▼ ]
[ + 새 카테고리 ]

[ 설정 완료 ]
```

### 값의 의미

```text
Google 계정으로 계속
→ 공용 Apps Script 권한 승인

파일 링크
→ 현재 사용자가 자기 Google Sheets URL 입력

파일 연결
→ connect-file
→ 사용자별 UserProperties에 파일 ID/이름 등록
```

공용 Apps Script URL은 이 화면 입력값이 아닙니다. 모바일 북마클릿 코드 내부 `GAS_WEBAPP_URL`에 들어갑니다.

## 3. 본 화면 상단

```text
YouTube 수집
────────────────

[썸네일]
영상 제목
채널명 · 업로드일 · 길이 · 조회수
```

## 4. 가져올 항목

```text
1. 가져올 항목

[ 영상 ] [ 음성 ] [ 데이터 ]

※ 복수 선택 가능
```

선택하지 않은 항목의 세부 UI는 숨깁니다.

### 영상

```text
화질
[ 360p ▼ ]

※ 실제 가능한 화질만 표시
```

### 음성

```text
음질
[ 최고 음질 ▼ ]

※ 실제 가능한 음질만 표시
```

### 데이터

```text
기본정보
☑ 썸네일
☑ 제목
☑ 영상 URL
☑ 채널명
☑ 업로드일
☑ 영상 길이
☑ 조회수

내용
☑ 설명
☑ 태그
☑ 대본
☐ 댓글

댓글 선택 시
수량 [100 ▼]
정렬 [인기순 ▼]

고급 ▾
☐ 좋아요
☐ 자막 원본
☐ 영상 ID
☐ 채널 ID
☐ 원본 메타데이터
```

댓글 옵션은 댓글 선택 시에만 표시합니다.

## 5. 데이터 형식

데이터를 선택했을 때만 표시합니다.

```text
2. 데이터 형식
[ 원문 ▼ ]

원문 / TXT / JSON
```

- `원문`: 사람이 읽고 AI에도 전달하기 쉬운 정리형 텍스트
- `TXT`: 일반 텍스트
- `JSON`: 구조화 데이터

## 6. 저장 위치

```text
3. 저장 위치

[ 로컬 ] [ Drive ]
```

### 로컬

```text
Android 파일 저장 선택창에서
폴더/파일명을 직접 선택
```

### Drive

데이터를 선택한 경우 순서는 반드시 **파일 → 시트 → 카테고리**입니다.

```text
파일
[ 연결된 Sheets 파일 ▼ ]
[ + 파일 연결 ] [ 열기 ]

↓

시트
[ 데이터 시트 ▼ ]
[ + 새 시트 ] [ 열기 ]

↓

카테고리
[ 카테고리 ▼ ]
[ + 새 카테고리 ]
```

`안내` 시트는 목록에 존재할 수 있지만 데이터 저장 대상으로 선택할 수 없습니다.

영상/음성 Drive 저장은 데이터 Sheets 경로와 별도이며 Google 공식 Save to Drive 버튼을 사용합니다.

## 7. 관리정보

`데이터 + Drive`일 때만 표시합니다.

```text
4. 관리정보

내 태그
[____________________]

활용 목적
[ 선택 안 함 ▼ ]
공부 / 자료조사 / 아이디어 / 보관

중요도
[ ☆ ] [ ☆ ] [ ☆ ] [ ☆ ] [ ☆ ]

상태
[ 미분석 ▼ ]
미분석 / 분석중 / 완료 / 보류

메모
[________________________]
[________________________]

☐ AI에게 보낼 항목으로 표시
```

중요도 범위는 `1~5`이며 선택하지 않은 상태도 허용합니다.

## 8. 중복 발견

같은 `영상 ID`가 선택한 데이터 시트에 존재할 때만 표시합니다.

```text
이미 수집된 영상입니다.

[ 기존 기록 열기 ]

○ 업데이트
○ 새 기록 추가
```

중복이 없으면 영역 자체를 숨깁니다.

## 9. 하단 동작

```text
[ 저장 ] [ 닫기 ]
```

`저장`은 선택된 항목과 저장 위치를 한 번에 처리합니다.

## 10. 표시 조건

```text
영상 선택
└─ 화질

음성 선택
└─ 음질

데이터 선택
├─ 데이터 필드
└─ 데이터 형식

로컬 선택
└─ Android 파일 저장

Drive 선택 + 데이터
├─ 파일
├─ 시트
├─ 카테고리
└─ 관리정보

Drive 선택 + 영상/음성
└─ Google Save to Drive 버튼

중복 발견
└─ 기존 기록 / 업데이트 / 새 기록 추가
```

## 11. UI와 코드의 책임 분리

`ui.html`은 화면, 사용자 입력, 일반 파일 출력, Save to Drive 버튼 렌더링을 담당합니다.

UI가 직접 관리하지 않는 것:

```text
Apps Script /exec URL
YouTube 추출 규칙
실제 미디어 URL 상시 상태
Google OAuth token
SpreadsheetApp 호출
```

이 항목들은 모바일 북마클릿 코어 또는 Apps Script가 담당합니다.

메시지 형식은 `PROTOCOL.md`, Apps Script 통신은 `APPS_SCRIPT_BRIDGE.md`, Sheets 저장 규칙은 `SHEET_RULES.md`를 따릅니다.
