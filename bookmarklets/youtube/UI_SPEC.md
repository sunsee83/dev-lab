# YouTube 수집도구 UI 기준본

이 문서는 `bookmarklets/youtube/`의 **화면 구조 기준본**입니다.

앞으로 UI 구현과 수정은 이 문서를 기준으로 합니다.

## 전체 구조

- 북마클릿은 **1개**로 통합한다.
- 첫 실행 또는 Google 저장공간 설정이 없는 경우 `YouTube 수집도구 설정` 화면을 먼저 표시한다.
- 설정 완료 후에는 `YouTube 수집` 본 화면을 표시한다.
- 본 화면의 첫 선택은 항상 `영상 / 음성 / 데이터`이며 **복수 선택 가능**하다.
- 선택하지 않은 기능의 세부 UI는 표시하지 않는다.

---

# 1. 최초 설정 화면

```text
YouTube 수집도구 설정

Google 계정으로 계속

① 내 저장공간 만들기
[설정 시작]

자동 생성
✓ 내 Drive에 전용 폴더
✓ 내 Google Sheets 파일
✓ 기본 시트
✓ 기본 카테고리

저장 위치
Drive / YouTube 수집/

[설정 완료]
```

## 설정 결과

- 사용자 본인의 Google 계정을 사용한다.
- 사용자 본인의 Drive에 `YouTube 수집` 전용 폴더를 만든다.
- 전용 Google Sheets 파일을 만든다.
- 기본 시트를 만든다.
- 기본 카테고리를 만든다.
- 가족이나 다른 사용자의 저장공간과 공유하지 않는다.

# 3. 영상 선택 시

```text
── 영상 선택 시 ──

화질
[ 360p ▼ ]

※ 실제 가능한 화질만 표시
```

- 현재 검증된 통합 영상+음성 MP4는 360p이다.
- 구현 시 고정값을 가정하지 않고 실제 접근 가능한 화질 목록만 표시한다.

---

# 4. 음성 선택 시

```text
── 음성 선택 시 ──

음질
[ 최고 음질 ▼ ]

※ 실제 가능한 음질만 표시
```

- 실제 접근 가능한 음성 스트림만 표시한다.
- 화면에는 파일 형식명보다 사용자가 이해하기 쉬운 `음질` 중심으로 표시한다.

# 5. 데이터 선택 시

```text
── 데이터 선택 시 ──

기본정보
☑ 썸네일
☑ 제목
☑ 영상 URL
☑ 채널명
☑ 업로드일
☑ 영상 길이
☑ 조회수

내용
☑ 설명
☑ 태그
☑ 대본
☐ 댓글

댓글 선택 시
수량 [100 ▼]
정렬 [인기순 ▼]

고급 ▾
☐ 좋아요
☐ 자막 원본
☐ 영상 ID
☐ 채널 ID
☐ 원본 메타데이터
```

## 댓글 옵션

- 댓글을 선택했을 때만 `수량`과 `정렬`을 표시한다.
- 수량 기본값: `100`
- 정렬 기본값: `인기순`
- 정렬 선택지에는 최소 `인기순 / 최신순`을 둔다.

# 6. 데이터 형식

데이터를 선택했을 때만 표시한다.

```text
────────────────
2. 데이터 형식
※ 데이터 선택 시에만 표시

[ 원문 ▼ ]

원문
TXT
JSON

※ 원문:
사람과 AI가 바로 읽기 좋은
정리된 형태
```

## 형식 의미

- `원문`: 사람이 읽기 쉽고 AI에도 바로 전달하기 좋은 정리형 출력
- `TXT`: 텍스트 파일
- `JSON`: 구조화 데이터

# 7. 저장 위치

```text
────────────────
3. 저장 위치

[ 로컬 ] [ Drive ]

둘 중 하나 선택
```

## 로컬 선택 시

```text
── 로컬 선택 시 ──

저장할 때 Android에서
폴더/파일명 직접 선택
```

## Drive 선택 시

```text
── Drive 선택 시 ──

파일
[ YouTube Research ▼ ]
[ + 새 파일 ] [ 열기 ]

↓

시트
[ AI 자료 ▼ ]
[ + 새 시트 ] [ 열기 ]

↓

카테고리
[ 생성형 AI ▼ ]
[ + 새 카테고리 ]
```

## Drive 선택 순서

1. 파일 선택
2. 시트 선택
3. 카테고리 선택

각 단계에서 새 항목을 만들 수 있고, 새로 만든 항목은 즉시 현재 선택값이 된다.

`열기`는 해당 Google Sheets 파일 또는 선택 가능한 대상 화면으로 바로 이동하는 기능으로 사용한다.

# 8. 관리정보

`데이터 + Drive`일 때만 표시한다.

```text
────────────────
4. 관리정보
※ 데이터 + Drive일 때만 표시

내 태그
[____________________]

중요도
[ ☆ ] [ ☆ ] [ ☆ ]

상태
[ 미분석 ▼ ]

메모
[________________________]
[________________________]
```

## 관리정보 기본값

- 중요도: 선택 없음 또는 0
- 중요도 최대: 3
- 상태 기본값: `미분석`

---

# 9. 중복 데이터 발견 시

기존 데이터가 발견된 경우에만 표시한다.

```text
────────────────
※ 기존 데이터 발견 시에만

이미 수집된 영상입니다.

[ 기존 기록 열기 ]

○ 업데이트
○ 새 기록 추가
```

중복이 없으면 이 영역 자체를 표시하지 않는다.

---

# 10. 하단 동작

```text
────────────────

[ 저장 ] [ 닫기 ]
```

- `저장`: 현재 선택된 영상/음성/데이터와 저장 위치 설정에 따라 실행한다.
- `닫기`: 팝업을 닫는다.
- 별도의 `YouTube로 돌아가기` 버튼은 두지 않는다.

# 12. 코드 배치 기준

상위 `bookmarklets/README.md` 원칙을 그대로 따른다.

## 북마클릿 내부

YouTube에 직접 의존하는 짧고 중요한 로직만 둔다.

- 현재 일반 영상/Shorts 식별
- YouTube player 응답 접근
- 영상/음성 스트림 판별
- YouTube 전용 최소 데이터 추출

## 공개 GitHub 폴더

길거나 일반화 가능한 기능을 둔다.

- 전체 팝업 UI
- 조건부 화면 표시
- 폼/상태 관리
- 로컬 저장 일반 로직
- TXT/JSON 출력
- Drive/Sheets 일반 UI
- 메시지 프로토콜
- 기타 일반 유틸리티

## 금지

다음 값은 GitHub와 북마클릿 어디에도 저장하지 않는다.

- API 키
- 비밀번호
- OAuth access/refresh token
- 로그인/세션 토큰
- 인증 쿠키
- 기타 계정 비밀정보

---

# 13. 현재 구현 우선순위

1. 하나의 북마클릿으로 `영상 / 음성 / 데이터` 통합
2. 기존에 성공한 영상/음성 로컬 저장 코어 유지
3. 위 기준본대로 통합 팝업 UI 구현
4. Drive 저장 기능 검증 및 연결
5. 데이터 수집 항목 연결
6. 최초 설정/Drive/Sheets 구조 연결
7. 중복 확인 및 관리정보 연결
