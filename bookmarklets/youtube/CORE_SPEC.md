# YouTube 북마클릿 코어 기준

이 문서는 **모바일 북마크의 `javascript:` 코드 안에 들어가는 YouTube 전용 코어의 책임**을 정의합니다.

실제 YouTube 전용 식별/추출/스트림 판별 코드는 모바일 북마크 URL 안에 유지합니다.

## 1. 모바일 북마크에 포함되는 외부 엔드포인트

다음 Apps Script 웹앱 URL은 **모바일 북마클릿 JavaScript 내부의 고정 상수**입니다.

```text
GAS_WEBAPP_URL =
https://script.google.com/macros/s/AKfycbxNvYE5AxCJ_9yNI_mS1GKOrRMBX6Qy3_u9CkUvNyiyOM0aof_CNaUDa0lEGHDFCdsa/exec
```

배치 위치:

```text
Android 모바일 브라우저
→ 북마크 편집
→ URL
→ javascript:(()=>{ ... GAS_WEBAPP_URL ... })()
```

이 값은 공용 Apps Script 주소입니다. 개인 Sheets URL은 북마클릿에 고정하지 않습니다.

## 2. 코어 역할

북마클릿 코어는 다음을 담당합니다.

1. 현재 페이지가 일반 영상인지 Shorts인지 식별
2. 현재 영상 ID 확인
3. 현재 영상의 기본 메타데이터 확인
4. 접근 가능한 영상 스트림 조사
5. 접근 가능한 음성 스트림 조사
6. 실제 가능한 화질/음질 목록 생성
7. 사용자가 선택한 영상/음성 스트림 확정
8. 로컬 저장 시 실제 미디어 fetch 및 파일 저장 실행
9. 데이터 선택 시 YouTube 전용 최소 추출 실행
10. 공개 UI와 메시지 송수신
11. `GAS_WEBAPP_URL`로 Apps Script 브리지 요청 전송

## 3. 보존해야 할 검증 동작

- 일반 영상 식별 및 저장
- Shorts 식별 및 저장
- 영상: 영상+음성이 함께 포함된 MP4 저장
- 음성: 음성 전용 파일 저장
- 실제 접근 가능한 형식만 후보로 사용
- 현재 검증 화질: 360p
- 저장 시 브라우저 파일 저장 선택 흐름 사용

고화질 영상/음성 분리 스트림 병합은 코어 기본 범위에 넣지 않습니다.

## 4. 코어 내부 상태

UI에는 실제 스트림 주소를 상시 전달하지 않습니다.

코어 내부에서는 실행 중에만 다음 상태를 유지합니다.

- 현재 영상 ID
- 현재 영상 메타데이터
- 영상 후보 목록
- 음성 후보 목록
- UI 선택값과 실제 스트림 후보의 대응표
- 현재 실행 token
- Apps Script bridge nonce

페이지를 새로고침하거나 실행을 종료하면 다시 조사합니다.

## 5. UI에 전달할 정보

### 영상 정보

- 썸네일
- 제목
- 채널명
- 업로드일
- 길이
- 조회수

### 미디어 선택지

- 영상: 사용자 표시용 화질명 + 코어 내부 후보를 가리키는 임시 ID
- 음성: 사용자 표시용 음질명 + 코어 내부 후보를 가리키는 임시 ID

UI는 실제 스트림 URL을 알 필요가 없습니다.

## 6. 영상 후보 규칙

- 바로 재생 가능한 영상+음성 통합 스트림 우선
- 실제 URL이 존재하는 후보만 사용
- 접근 가능한 후보만 UI에 표시
- 같은 화질 후보가 여러 개면 코어가 대표 후보 선택
- 검증된 성공 경로 우선 보존

## 7. 음성 후보 규칙

- 음성 전용 스트림만 후보로 사용
- 실제 접근 가능한 후보만 사용
- 가능한 후보를 음질 기준으로 정렬
- UI에는 파일 확장자보다 `음질` 중심으로 표시

## 8. 로컬 저장

사용자가 `로컬`을 선택하면 실제 파일 저장은 YouTube 페이지 안의 코어에서 실행합니다.

### 영상

- 선택된 영상 후보 fetch
- Android 브라우저 파일 저장 흐름 사용
- MP4 파일명 생성

### 음성

- 선택된 음성 후보 fetch
- Android 브라우저 파일 저장 흐름 사용
- 음성 파일명 생성

파일명은 영상 제목을 기본으로 하고 사용할 수 없는 문자는 정리합니다.

## 9. Drive/Sheets 저장

데이터를 Google Sheets에 저장할 때:

```text
북마클릿 코어
→ GAS_WEBAPP_URL
→ Transport.gs
→ Code.gs
→ SpreadsheetApp
→ 사용자가 연결한 Sheets
```

개인 Sheets URL은 설정 UI의 `connect-file` 입력으로만 전달합니다.

영상/음성 Drive 저장은 Google 공식 Save to Drive 경로를 사용합니다.

## 10. 데이터 수집

데이터 코어는 `UI_SPEC.md`에서 사용자가 선택한 필드만 조사합니다.

기본 필드:

- 썸네일
- 제목
- 영상 URL
- 채널명
- 업로드일
- 영상 길이
- 조회수
- 설명
- 태그
- 대본
- 댓글
- 좋아요
- 자막 원본
- 영상 ID
- 채널 ID
- 원본 메타데이터

댓글/대본처럼 추가 요청이 필요한 항목은 선택되지 않았으면 호출하지 않습니다.

## 11. 오류 원칙

한 기능의 실패가 다른 기능을 깨뜨리지 않도록 분리합니다.

- 데이터 실패 + 영상 성공 → 영상 저장 가능
- 음성 후보 없음 + 영상 후보 있음 → 영상만 선택 가능
- Drive/Sheets 실패 → 로컬 저장 경로 유지

UI에는 사용자가 처리할 수 있는 짧은 상태 문구만 전달합니다.

## 12. 공개 저장소 금지 항목

- 실행 중 얻은 미디어 URL
- 로그인/세션 정보
- 인증 쿠키
- OAuth access/refresh token
- 개인 계정 비밀값

Apps Script `/exec` URL은 비밀값이 아니며 모바일 북마클릿의 공용 엔드포인트로 문서화합니다.

세부 메시지 형식은 `PROTOCOL.md`, Apps Script 통신은 `APPS_SCRIPT_BRIDGE.md`를 따릅니다.
