# YouTube 수집도구

YouTube 모바일 웹에서 사용하는 **서버 없는 통합 북마클릿 프로젝트**입니다.

상위 `bookmarklets/README.md`의 코드 배치·보안 원칙을 그대로 적용합니다.

## 기준 문서

화면 구조와 표시 조건의 기준본은 [`UI_SPEC.md`](./UI_SPEC.md)입니다.

UI를 구현하거나 수정할 때는 `UI_SPEC.md`를 우선 기준으로 합니다.

## 목표

북마클릿은 **1개**로 통합합니다.

실행 후 첫 단계에서 다음 항목을 선택합니다.

- 영상
- 음성
- 데이터

세 항목은 복수 선택할 수 있습니다.

선택 결과에 따라 필요한 세부 UI만 표시합니다.

## 최초 설정

Google 저장공간 설정이 없는 사용자는 먼저 `YouTube 수집도구 설정` 화면을 사용합니다.

목표 설정 결과:

- 사용자 본인의 Google 계정 사용
- 사용자 본인의 Drive에 `YouTube 수집` 전용 폴더 생성
- Google Sheets 파일 생성
- 기본 시트 생성
- 기본 카테고리 생성

사용자별 저장공간은 서로 분리합니다.

## 본 화면 기능

### 영상

- 실제 접근 가능한 화질만 표시
- 로컬 저장
- Drive 저장
- 현재 검증된 통합 영상+음성 MP4: 360p

### 음성

- 실제 접근 가능한 음질만 표시
- 로컬 저장
- Drive 저장

### 데이터

기본정보:

- 썸네일
- 제목
- 영상 URL
- 채널명
- 업로드일
- 영상 길이
- 조회수

내용:

- 설명
- 태그
- 대본
- 댓글

고급:

- 좋아요
- 자막 원본
- 영상 ID
- 채널 ID
- 원본 메타데이터

데이터 형식:

- 원문
- TXT
- JSON

## 저장 위치

### 로컬

Android 저장 UI에서 폴더와 파일명을 선택합니다.

### Drive

순서대로 선택합니다.

1. 파일
2. 시트
3. 카테고리

각 단계에서 새 항목을 만들 수 있습니다.

## 관리정보

`데이터 + Drive`일 때만 표시합니다.

- 내 태그
- 중요도 1~3
- 상태
- 메모

## 중복 처리

기존 데이터가 발견됐을 때만 중복 영역을 표시합니다.

- 기존 기록 열기
- 업데이트
- 새 기록 추가

## 코드 배치 원칙

### 북마클릿 안에 남기는 것

YouTube 구조에 직접 의존하는 짧고 중요한 로직만 둡니다.

- 현재 일반 영상/Shorts 식별
- YouTube 전용 player 응답 접근
- 영상/음성 스트림 판별
- YouTube 전용 최소 데이터 추출 규칙

이 핵심 로직은 공개 폴더에 복제하지 않습니다.

### 공개 GitHub 폴더에 두는 것

길거나 일반화 가능한 기능을 둡니다.

- 전체 팝업 UI
- 조건부 화면 표시
- 폼/상태 관리
- 로컬 파일 저장 일반 로직
- TXT/JSON 출력
- Drive/Sheets 일반 UI
- 메시지 프로토콜
- 기타 일반 유틸리티

GitHub는 코드 저장소 역할만 하며, 별도 백엔드 서버를 전제로 하지 않습니다.

## 보안

다음 값은 저장소와 북마클릿 어느 쪽에도 하드코딩하지 않습니다.

- API 키
- 비밀번호
- OAuth access/refresh token
- 로그인/세션 토큰
- 인증 쿠키
- 기타 계정 비밀정보

사용자 인증이 필요한 기능은 사용자의 브라우저와 Google 공식 인증 흐름을 사용합니다.

## 현재 검증 상태

Android 모바일 Whale + YouTube 모바일 웹에서 다음을 확인했습니다.

- 일반 영상: 통합 영상+음성 MP4 로컬 저장 성공
- Shorts: 통합 영상+음성 MP4 로컬 저장 성공
- 음성 전용 로컬 저장 성공
- 현재 검증된 통합 MP4 화질: 360p
- 고화질 영상은 별도 영상/음성 스트림 병합이 필요한 과제
- Drive 저장은 별도 검증 단계
