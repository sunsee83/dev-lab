# YouTube 수집도구 Sheets 읽기/쓰기 규칙

이 문서는 Apps Script + `SpreadsheetApp` 방식에서 Google Sheets를 어떻게 읽고 쓰는지 고정합니다.

## 기본 구조

```text
가로 = 항목(열)
세로 = 영상(행)
한 영상 = 한 행
```

- 1행은 고정 헤더입니다.
- 2행부터 영상 데이터가 아래로 쌓입니다.
- 첫 번째 탭 `안내`는 데이터 저장 대상이 아닙니다.
- 파일당 `안내 1 + 데이터 시트 최대 10` 구조를 사용합니다.
- 데이터 시트당 수집 기록은 최대 2,000개입니다.

---

## 읽기 범위

도구는 필요한 범위만 읽습니다.

- 사용자가 직접 연결한 Spreadsheet만 엽니다.
- Drive 전체 파일 목록은 탐색하지 않습니다.
- 파일 연결 시 파일명과 시트 목록을 확인합니다.
- 데이터 저장 시 선택한 데이터 시트의 헤더를 확인합니다.
- 중복 확인은 선택한 데이터 시트의 `영상 ID`를 기준으로 합니다.
- 업데이트 시 해당 영상 ID가 있는 현재 행만 읽습니다.
- `안내` 시트는 안내 내용 유지에 필요한 범위만 사용합니다.

연결되지 않은 Spreadsheet의 내용을 임의로 읽지 않습니다.

---

## 쓰기 범위

도구가 자동으로 쓰는 위치는 다음 두 곳뿐입니다.

1. 연결 파일의 첫 번째 `안내` 시트
2. 사용자가 선택한 데이터 시트의 관리 열 범위

도구는 파일, 시트, 행을 자동 삭제하지 않습니다.

`파일 연결 해제`는 연결 설정만 제거하며 실제 Google Sheets 파일이나 데이터를 삭제하지 않습니다.

---

## 열 구분

### 1. 원본 / 자동 수집 열

YouTube에서 가져오는 값입니다.

- 썸네일
- 제목
- 채널명
- 업로드일
- 영상 길이
- 조회수
- 좋아요
- 영상 언어
- 태그 / 해시태그
- 설명
- 대본
- 댓글
- 영상 URL
- 영상 ID
- 채널 ID
- 자막 원본
- 원본 메타데이터

업데이트 규칙:

- 이번 수집에서 **성공적으로 확보한 항목만** 새 값으로 갱신합니다.
- 사용자가 이번에 선택하지 않은 항목은 기존 값을 유지합니다.
- 수집 실패한 항목 때문에 기존 값을 빈칸으로 만들지 않습니다.
- `영상 ID`는 행의 식별자로 사용하며 기존 기록 업데이트 시 다른 ID로 바꾸지 않습니다.

즉 재수집은 `성공한 원본 필드만 새로고침` 방식입니다.

### 2. 사용자 관리 열

사용자가 직접 분류하고 관리하는 값입니다.

- 카테고리
- 활용 목적
- 중요도
- 상태
- 내 태그
- 메모
- 인상적인 구간
- 관련 그룹 ID
- AI 전송

업데이트 규칙:

- YouTube 재수집만으로는 기존 사용자 관리값을 덮어쓰지 않습니다.
- 북마클릿에서 사용자가 해당 값을 직접 변경한 경우에만 갱신합니다.
- 사용자가 Sheets에서 직접 수정한 값도 다음 재수집 때 기본적으로 유지합니다.
- 값을 지우는 동작은 일반 빈값과 구분해 명시적인 `지우기` 요청으로 처리합니다.

### 3. AI 생성 열

AI 분석 결과를 저장하는 영역입니다.

- AI 요약
- 핵심 주장
- 핵심 키워드
- 사실확인 필요
- 댓글 반응 요약
- 타임스탬프 핵심

업데이트 규칙:

- Apps Script가 자체적으로 AI 내용을 생성하지 않습니다.
- 실제 AI 결과가 전달된 경우에만 해당 열을 씁니다.
- 새 AI 결과가 없는 일반 재수집에서는 기존 AI 결과를 유지합니다.
- 향후 GPT / Gemini / Claude별 결과 열이 필요하면 AI 영역 오른쪽에 추가합니다.

### 4. 시스템 열

- 수집일시
- 수정일시

규칙:

- `수집일시`는 처음 행을 만든 시각을 유지합니다.
- `수정일시`는 도구가 해당 행을 실제로 수정할 때 갱신합니다.

---

## 링크 / 썸네일 표시

- 썸네일은 작은 미리보기로 표시합니다.
- 원본 이미지 파일 자체를 Sheets에 첨부하지 않습니다.
- 제목은 해당 YouTube 영상으로 연결합니다.
- 채널 ID를 확보한 경우 채널명은 해당 채널로 연결합니다.
- 영상 URL은 별도 원본 값으로도 보존합니다.
- 제목/채널 링크는 수집한 임의 문자열을 수식으로 실행하지 않고 검증된 YouTube 주소만 사용합니다.
- 외부 텍스트가 `=`, `+`, `-`, `@` 등으로 시작해도 Sheets 수식으로 실행되지 않도록 차단합니다.

---

## 헤더와 사용자 수정

도구가 관리하는 열 이름과 순서는 고정합니다.

- 관리 열 사이에 새 열을 끼워 넣거나 헤더 이름을 바꾸면 자동 저장을 중단합니다.
- 기존 내용을 임의로 덮어써서 구조를 복구하지 않습니다.
- 사용자가 별도 열을 만들고 싶으면 **도구 관리 열의 오른쪽 끝 이후**에 추가할 수 있습니다.
- 오른쪽에 추가한 사용자 열은 도구가 읽거나 덮어쓰지 않습니다.
- 행 정렬과 필터 사용은 허용합니다. 업데이트는 행 번호가 아니라 영상 ID를 다시 확인합니다.

---

## 중복 규칙

중복 기준은 `영상 ID`입니다.

현재 기본 범위는 **사용자가 선택한 데이터 시트 안**입니다.

- 같은 영상 ID가 없으면 새 행 추가
- 같은 영상 ID가 있으면 `기존 기록 열기 / 업데이트 / 새 기록 추가` 선택
- 여러 행에 같은 영상 ID가 있으면 업데이트할 행을 명확히 선택하기 전에는 자동 수정하지 않음

다른 파일/다른 시트까지 전역 중복으로 묶는 기능은 기본 동작에 넣지 않습니다.

---

## 용량 제한

```text
연결 파일                 최대 10개
파일당 안내 시트          1개
파일당 데이터 시트        최대 10개
파일당 전체 시트          최대 11개
데이터 시트당 기록        최대 2,000개
1,800개                   새 시트 사용 권장 경고
2,000개                   새 기록 추가 차단
기존 기록 업데이트        허용
```

한도에 도달해도 도구가 데이터를 자동 이동하거나 삭제하지 않습니다.

사용자가 새 데이터 시트 또는 다른 연결 파일을 선택합니다.

---

## 안내 시트에 표시할 짧은 규칙

실제 `안내` 탭에는 긴 설명 대신 아래 핵심만 표시합니다.

```text
데이터 구조
• 가로 = 항목, 세로 = 영상
• 한 영상 = 한 행

제한
• 안내 1개 + 데이터 시트 최대 10개
• 데이터 시트당 최대 2,000개
• 1,800개부터 새 시트 사용 권장
• 2,000개부터 신규 추가 중지, 기존 기록 수정 가능

기본 규칙
• 영상 ID로 중복 확인
• 수집 실패 항목은 기존 값을 지우지 않음
• 사용자 관리값은 일반 재수집으로 덮어쓰지 않음
• 수집일 유지 / 수정일 자동 갱신
• 도구는 파일·시트·행을 자동 삭제하지 않음
```

이 문서를 기준으로 단계 9의 실제 Sheets 저장 로직과 UI 메시지를 구현합니다.
