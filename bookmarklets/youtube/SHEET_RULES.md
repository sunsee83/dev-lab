# Sheets 읽기/쓰기 규칙

## 구조

```text
가로 = 항목(열)
세로 = 영상(행)
한 영상 = 한 행
```

- 1행: 고정 헤더
- 2행부터: 영상 데이터
- 첫 탭 `안내`: 저장 대상 아님

## 저장 규칙

- 중복 기준: `영상 ID`
- 재수집: 성공한 원본 항목만 갱신
- 미수집/실패 항목: 기존값 유지
- 사용자 관리값: 사용자가 바꾼 경우만 갱신
- 값 삭제: 명시적인 지우기 요청일 때만
- AI 결과: 새 결과가 있을 때만 갱신
- `수집일시`: 최초값 유지
- `수정일시`: 실제 저장/수정 시 갱신
- 파일·시트·행 자동 삭제 없음

## 열 보호

- 도구 관리 헤더의 이름/순서는 고정
- 구조가 다르면 자동 덮어쓰기 금지
- 사용자 추가 열은 도구 열 오른쪽에만 추가
- 정렬/필터 사용 가능, 업데이트는 영상 ID 재확인

## 제한

```text
연결 파일          10개
안내 시트          1개
데이터 시트        파일당 10개
전체 시트          파일당 11개
기록               시트당 2,000개
경고               1,800개부터
2,000개 도달       신규 추가 차단 / 기존 수정 허용
```

## 안내 시트 표시

- 저장 경로
- 가로=항목 / 세로=영상
- 위 제한
- 영상 ID 중복 확인
- 실패 항목·사용자 관리값 기존값 보존
- 수집일 유지 / 수정일 자동 갱신
- 자동 삭제 없음
