# Sheets 읽기/쓰기 규칙

## 구조

```text
가로 = 항목(열)
세로 = 영상(행)
한 영상 = 한 행
```

- 1행: 고정 헤더
- 2행부터: 영상 데이터
- 첫 탭 `안내`: 저장 대상 아님
- 사용자 추가 열은 관리 열(A~AH) 오른쪽에만 추가

## 기록 행 판정

기록 수와 새 기록 위치는 **시트 전체의 마지막 행이 아니라 `영상 ID` 열(AC)** 기준으로 계산합니다.

```text
영상 ID가 있는 행 = 유튜브다운로드 기록
영상 ID가 없는 행 = 기록 수에 포함하지 않음
```

따라서 사용자가 오른쪽 추가 열의 먼 아래 행에 값을 적어도 기록 수가 늘어나거나 새 영상이 그 아래로 밀리지 않습니다.

새 기록은 `영상 ID` 열에서 2~2001행 사이의 첫 빈 기록 행을 사용합니다.

## 저장 규칙

- 중복 기준: `영상 ID`
- 재수집: 성공한 원본 항목만 갱신
- 미수집/실패 항목: 기존값 유지
- 사용자 관리값: 사용자가 바꾼 경우만 갱신
- 값 삭제: 명시적인 지우기 요청일 때만
- AI 결과: 새 결과가 있을 때만 갱신
- `수집일시`: 최초값 유지
- `수정일시`: 실제 저장/수정 시 갱신
- 파일·시트·행 자동 삭제 없음

## 카테고리 저장

카테고리 목록은 새로 추가할 때 `UserProperties`에 계속 누적하지 않습니다.

```text
UserProperties
→ 연결 파일 ID / 기본 파일 등 최소 사용자 상태

각 Google Sheets의 안내 탭 숨김 관리영역(C:D)
→ 시트명 / 카테고리
```

이렇게 해서 카테고리가 해당 Sheets 파일과 함께 이동하고 사용자 설정 저장공간이 커지는 문제를 막습니다.

구버전 `UserProperties`에 남아 있는 카테고리는 읽을 때 안내 탭 관리영역으로 호환 반영합니다.

## 열 보호

- 도구 관리 헤더의 이름/순서는 고정
- 구조가 다르면 자동 덮어쓰기 금지
- 사용자 추가 열은 도구 열 오른쪽에만 추가
- 정렬/필터 사용 가능, 업데이트는 영상 ID 재확인

## 제한

```text
연결 파일          10개
안내 시트          1개
데이터 시트        파일당 10개
전체 시트          파일당 11개
기록               시트당 2,000개
경고               1,800개부터
2,000개 도달       신규 추가 차단 / 기존 수정 허용
카테고리           데이터 시트당 30개
셀 문자열          최대 약 49,000자
```

## 장문 데이터 정책

Sheets 셀 하나에 들어가는 문자열은 최대 약 49,000자로 제한합니다.

```text
49,000자 이하
→ 그대로 저장

49,000자 초과
→ 49,000자 안에서 자름
→ 끝에 [일부 내용 생략] 표시
→ 저장 결과에 잘린 열 이름 표시
```

이 정책은 대본, 댓글, 자막 원본, 원본 메타데이터와 긴 관리정보에 동일하게 적용합니다. 장문 데이터 때문에 별도 시트나 파일을 자동 생성하지 않으며, 기존 파일·시트 수 제한과 한 영상 한 행 구조를 유지합니다.

로컬 TXT/JSON 저장에는 이 Sheets 셀 제한을 적용하지 않습니다.

## 안내 시트

사용자에게 보이는 A열에는 저장 규칙을 표시합니다.

도구 내부 카테고리 관리값은 C:D 열에 저장하고 기본적으로 숨깁니다. `ensureGuide_()`는 안내 문구 A열만 갱신하며 이 내부 관리영역은 지우지 않습니다.
