# YouTube 영상·음성 로컬 저장

이 문서는 통합 UI의 `영상 / 음성` 선택을 Android 모바일 로컬 저장 경로에 연결하는 **현재 규격**입니다.

YouTube 전용 스트림 추출 코드는 모바일 북마클릿 코어에 유지합니다.

## 1. UI 초기화

북마클릿 코어는 UI에 다음만 전달합니다.

```text
영상 정보
실제 사용 가능한 영상 화질 목록
실제 사용 가능한 음성 음질 목록
각 후보를 가리키는 임시 ID
```

실제 미디어 URL은 초기화 메시지에 포함하지 않습니다.

## 2. UI 선택

사용자는 `영상`, `음성`, 또는 둘 다 선택할 수 있습니다.

```text
영상 선택 → 화질
음성 선택 → 음질
저장 위치 로컬 → save-local
```

## 3. 임시 후보 ID

코어는 UI가 반환한 임시 ID를 현재 실행의 후보표에서 실제 스트림으로 해석합니다.

```text
video.id → 영상+음성 통합 MP4 후보
audio.id → 음성 전용 후보
```

후보표와 실제 URL은 현재 북마클릿 실행 메모리에만 유지합니다.

## 4. 영상 저장

```text
영상 제목 기반 .mp4 파일명 생성
→ 금지 문자 정리
→ showSaveFilePicker()
→ 선택 미디어 URL fetch
→ 필요 시 Range: bytes=0-
→ response.body.pipeTo(await handle.createWritable())
```

검증된 범위:

- Android Whale
- 일반 영상
- Shorts
- 영상+음성 통합 MP4
- 현재 직접 저장 검증 화질 360p

## 5. 음성 저장

```text
영상 제목 기반 음성 파일명 생성
→ showSaveFilePicker()
→ 선택 음성 전용 URL fetch
→ 응답 스트림을 파일에 기록
```

현재 검증 경로는 `audio/mp4` 계열입니다.

## 6. 복수 선택

영상과 음성을 함께 선택하면 각각 독립 작업으로 처리합니다.

한 항목의 취소/실패가 다른 항목의 성공 결과를 취소하지 않습니다.

## 7. 상태 메시지

```text
영상 저장 준비 중…
영상 저장 완료
영상 저장 실패
영상 저장 취소됨

음성 저장 준비 중…
음성 저장 완료
음성 저장 실패
음성 저장 취소됨
```

## 8. 저장 경계

공개 UI/문서에 둘 수 있는 것:

```text
임시 ID 규격
일반 파일 저장 흐름
상태 처리
```

실행 중 외부에 저장하지 않는 것:

```text
실제 미디어 URL
계정/세션 정보
인증 쿠키
OAuth token
```

YouTube 추출 규칙은 `CORE_SPEC.md`, UI 메시지는 `PROTOCOL.md`를 따릅니다.
